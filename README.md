# 📱 Sister Sneak: Phone Locked 🔒

> A cozy Gujarati joint-family 2D social-deduction visual novel & multiplayer game built with HTML5 Canvas, modern ES6 JavaScript, and Centralized WebSockets.

---

## 🌟 Premise

The On-Duty Mummy has locked all five sisters' phones in the heirloom steel box! Nobody gets their phone back until the entire 3-floor mansion is **100% clean**. But one sister is secretly the **Imposter**, sabotaging household chores, causing power blackouts, and framing others during Emergency Family Meetings.

---

## 🎮 Key Features

- **🏰 3-Floor Cutaway House Map:**
  - **3F (Terrace):** Clothesline, fluttering sarees, black Sintex water tank.
  - **2F (Living Hub):** Central Hall (Phone Lockbox), Grand Kitchen, Balcony, Bedroom.
  - **1F (Ground Entry):** Veranda, Shoe Rack, Rangoli, Store Room, Chai Counter, Switchboards.
- **👧 5 Playable Sisters with Unique Active Powers:**
  - **🌸 Riddhi:** Partner Courage (+80% speed boost) / Blanket Stealth (Fake alibi invisibility).
  - **🎨 Shruti:** Artistic Flow (+25% Cleanliness boost) / Fake Clue Fabricator (Frame sisters).
  - **🎒 Jahanvi:** Shortcut Master (Super Dash) / Floor Teleport (Instant portal).
  - **📚 Jisha:** Universal Ladli Card (Wipe Mummy's suspicion) / Innocent Shield (Vote immunity).
  - **⚡ Jyeana:** Quick Hint & Dash / Rapid Saboteur (Reset sabotage cooldowns).
- **👩‍🦱 4 Selectable Round Inspector Mummies:**
  - **Riddhi & Jahanvi's Mummy (Sohini Mummy):** Strict on discipline & bedsheet folding.
  - **Shruti ni Mummy:** Perfectionist on kitchen counters & glassware alignment.
  - **Jisha ni Mummy:** Monitors homework sheets, study desks & screen time.
  - **Jyeana ni Mummy:** Eagle-eyed switchboard & power bill inspector.
- **🧹 8 Interactive Chore Mini-Games:** Dry clothes collection, fridge water refill, bedsheet straightening, power switches, footwear matching, mango achar hunt, chai glass alignment, and balcony plant watering.
- **🌐 Real-Time Online Multiplayer (Centralized WebSockets):**
  - Share 4-letter room codes (`SNEK42`, `CHAI88`).
  - Play across devices and different networks (Android, iOS, PC, Mac).
  - Automatic AI bot backfill if fewer than 5 human players join.
- **📱 Mobile Touch Controls:** Virtual analog joystick + action FAB button for Android and iOS touchscreens.
- **🔊 Procedural Web Audio Synth:** Zero external audio files needed; sounds are generated in real-time.

## 🚀 Quick Start (Local)

1. Clone repository:
   ```bash
   git clone https://github.com/MoNiLBaRiYa/Sister-Sneak.git
   cd Sister-Sneak
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start server:
   ```bash
   npm start
   ```
4. Open [http://localhost:8080/](http://localhost:8080/) in your browser.

## ☁️ 1-Click Online Deployment (Free Hosting)

### Deploy on [Render.com](https://render.com)

   - **Environment:** `Node`
   - **Build Command:** `npm install`
